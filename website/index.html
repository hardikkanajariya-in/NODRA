Your notes, blocks, and links — online and under your control.

NODRA is a block notebook for daily journals, connected pages, and a visual graph. Paste from Logseq and keep writing in nested bullets, page references, and properties.

View on GitHub Self-hosting guide

Built for how you already write

Journals

One page per day. Open today, yesterday, or any date in the sidebar.

Pages

Wiki-style pages with [[links]] that build your graph as you save.

Logseq paste

Nested bullets, tags, and properties from Logseq Markdown land in the editor.

Graph

See how journals and pages connect. Click a node to open it.

Self-hosting

NODRA runs as a Next.js app with PostgreSQL. You set a single access password in the environment — no user database required. 

git clone https://github.com/hardikkanajariya-in/NODRA.git
cd NODRA
pnpm install
cp .env.example .env.local
pnpm dev

Full details are in the README.
